# HR-Analytics-dashboard  - employee attrition , demographics and satisfacion insighs .
1. Project Title - HR Attrition and performance dashboard .
2. Short Description - A Power BI dashboard that visualizes employee attrition, satisfaction, and compensation data to help HR teams spot at-risk employee segments and take action to improve retention.
3. Tech stack - the dashboard was built using the following tools and insights : 
.⚡ Power BI Desktop – used to design and build the interactive dashboard/report
.🔄 Power Query (M Language) – used for data extraction, cleaning, and transformation (ETL)
.📐 DAX (Data Analysis Expressions) – used to create calculated measures like Attrition Count, Attrition %, and Average Income of Attrited Employees
.📄 Data Source: CSV file — imported and processed via Power Query
.🗂️ Data Model: Single flat table structure (no relationships / no star schema)
.📁 File Format: .pbit (Power BI Template)
4.  FEATURES :
1. Business Problem
Employee attrition is a costly and often unpredictable challenge for organizations, making it difficult for HR teams to identify which employees or departments are most at risk of leaving. Without a consolidated view of workforce data, decision-makers struggle to spot patterns behind turnover before it happens.

2. Goal
 The goal of this dashboard is to consolidate employee data — demographics, satisfaction, compensation, and tenure — into a single interactive view that helps HR identify attrition drivers. It aims to support faster, data-backed retention decisions instead of relying on guesswork or after-the-fact exit interviews.

3. Walkthrough of Key Visuals
The dashboard opens with KPI cards summarizing overall headcount, attrition count, and attrition rate, followed by a donut chart and pie chart breaking down attrition by gender and department. Bar, column, and area charts explore trends across job roles, salary slabs, and tenure, while a funnel visual and pivot table let users drill deeper into specific employee segments, with slicers enabling on-the-fly filtering.

4. Highlight
A key highlight of this dashboard is its ability to instantly filter and cross-analyze attrition against multiple factors — like overtime, job satisfaction, and salary — using interactive slicers, all within a single-page, easy-to-navigate layout. This makes it simple to move from a high-level attrition rate to root-cause exploration in just a few clicks.
